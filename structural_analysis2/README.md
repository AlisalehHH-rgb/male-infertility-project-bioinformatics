# Structural analysis

ChimeraX and PyMOL visualisations of missense variants over AlphaFold models, with pLDDT confidence values.

- ChimeraX images: `website2/img/chimerax/`
- PyMOL images: `website2/img/pymol/`
- Reproducible command files and the full structural archive: see the project Drive index (`docs2/google-drive-links.md`) and the thesis section 4.10 / 5.7.
- The analysis is descriptive and hypothesis-generating; it does not prove pathogenicity.
