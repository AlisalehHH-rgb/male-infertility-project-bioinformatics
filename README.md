# Results: figures and tables

This folder contains the thesis figures and tables in reusable formats.

## Figures

- `figures/` — 51 images extracted from the thesis source in document order.
- `figures/figures_index.csv` — file name, inline-shape index, content type, size and displayed dimensions.
- The PDF in `thesis2/` remains the authoritative version with captions and numbering.

## Tables

- `tables/` — 58 tables exported as CSV from the thesis source.
- `tables/tables_index.csv` — file name, source table index, row/column counts and first cell.
- CSV files are UTF-8 with BOM, so Arabic and Excel open them correctly.
- Complex merged cells may need the PDF for final formatting.

## Structural images

The ChimeraX and PyMOL images used by the website are in `website2/img/chimerax/` and `website2/img/pymol/`.
