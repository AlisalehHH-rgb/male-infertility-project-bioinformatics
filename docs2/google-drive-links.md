# Google Drive archive

This page indexes the **24 Google Drive folders** that contain the full execution archive of the project: prompts, commands, intermediate files, outputs, verification runs, Galaxy history and Colab workspaces. GitHub stores the index and the final materials; large raw and intermediate files remain in Google Drive.

> **Before publishing:** set every folder to **Share -> General access -> Anyone with the link -> Viewer**. Otherwise reviewers cannot open it.

## How to read the table

- **Folder:** the folder name as it appears in Drive.
- **Link:** opens the folder directly.
- **Track:** the tool or execution track.
- **Purpose:** why the folder exists and what it is for.
- **Contents:** the main files inside it.

## Recommended reading order

1. `Final - Google Colab` - the final reproducible Python/Colab workspace.
2. `Galaxy` - the platform track, VEP files and the Excel evidence matrix.
3. `Claude Opus 5.5`, `ChatGPT Plus (First Mission)`, `OpenCode (First Mission)`, `Devin`, `Gemini`, `Astra 6 - GPT` - the AI-tool runs.
4. The `Verification` and `Outputs` subfolders - the checks and final files for each tool.

## Notes

- Folder names are kept exactly as they appear in the thesis appendix.
- `Outputs` folders contain final files; parent folders contain prompts, code, logs and intermediate files.
- `Verification` folders contain the 14-variant verification task and its comparison with the documented reference.
- `Staged Rollout` folders contain the stage-by-stage execution of the full plan.
