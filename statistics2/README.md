# Statistics

Statistical analysis for the AI-tool comparison and the selection-rule stability checks.

- Tests: Cochran's Q, exact McNemar, Holm and Bonferroni correction, Wilson score intervals, Jaccard index, gene-clustered bootstrap (3,000 resamples, seed 20261012).
- Result tables: see `results2/tables/` (CSV) and the thesis chapter 5.
- Scripts: see `src2/` and `notebooks/Final_Organized_A_full_rerun.ipynb`.
- The website re-implements the same tests in `website2/js/stats.js`; values were matched against the Python results.
