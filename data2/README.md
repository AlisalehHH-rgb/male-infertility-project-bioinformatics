# Data sources and data access

Raw files are large and are **not** stored in this repository. They are downloaded from the official sources below
(these addresses are taken from the project code; check each one still resolves before publishing).

| Layer | Source |
|---|---|
| ClinVar variant summary | https://ftp.ncbi.nlm.nih.gov/pub/clinvar/tab_delimited/variant_summary.txt.gz |
| Male Fertility Gene Atlas (MFGA) | https://mfga.uni-muenster.de/publications |
| Ensembl REST (VEP, gene lookup) | https://rest.ensembl.org |
| gnomAD API (v4) | https://gnomad.broadinstitute.org/api |
| GTEx v8 bulk expression | https://gtexportal.org/home/downloads/adult-gtex/bulk_tissue_expression |
| Human Protein Atlas | https://www.proteinatlas.org |

Record the ClinVar release date and genome build (GRCh38) you used, because ClinVar changes monthly.
